Signals: signal, computed, effect

A signal is a value that tells Angular when it changes. Templates, computeds and effects that read it are tracked automatically, so Angular knows exactly what depends on what. That's the modern replacement for the plain fields of lessons 01–02.

If you ever used Knockout in an MVC app, signals are basically that idea back, with a compiler around it. jQuery has no equivalent: you update every affected DOM spot yourself.

1. signal & computed

{{ count() }} double (computed) = {{ double() }}

Read a signal by calling it: count(). The call is how Angular records "this template / computed depends on count". Forgetting the () prints the function, not the value. Templates can't contain arrow functions, so update(fn) goes in a class method (like changeQty below).

Signals compare with ===, like React's setState. Always update() with a new array / object.

3. effect

Two effects run in this page's constructor. Change a quantity and watch the browser tab title; reload the page and the quantities come back from localStorage.

  • No dependency array: the effect re-runs when any signal it read last time changes. No stale closures, no missing deps.
  • Use it only for things outside Angular's view: DOM APIs, storage, logging, and later handing values to GSAP or Three.js.
  • Don't use it to compute one signal from another. That's what computed is for (same advice as "you might not need an effect" in React).
  • Effects run asynchronously, after change detection, not synchronously on set(). Several sets in a row cause one run.
  • untracked(() => x()) reads a signal without subscribing to it (≈ useEffectEvent / reading a ref in React).

Also good to know

  • linkedSignal(() => list()[0]): a writable signal that resets when its source changes. Think "selected item that resets when the list changes", which in React needs a key reset or an effect.
  • The LikeButton from lesson 01 now uses a signal: compare it in the git diff.
  • Signals are what make OnPush and zoneless change detection practical (lesson 10). With zone.js on, plain fields still work, which is why the mutation demo half-works.
