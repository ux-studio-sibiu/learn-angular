Lesson 01

Components & template bindings

Angular templates are HTML with four extra syntaxes. Each one decides which way data flows: class → DOM, DOM → class, or both.

1. Interpolation

Any expression on the class: fields, methods, simple maths. It is turned into text (HTML-escaped, like JSX).

Name: {{ name }} · Upper: {{ name.toUpperCase() }} · Length: {{ name.length }} · Maths: {{ 6 * 7 }}

{{ greet() }}

Template expressions can't use globals (window, console), new or assignments. Only event bindings may assign. This is stricter than JSX, where anything JavaScript goes.

2. Event binding & template references

(event)="statement" runs when the DOM event fires; $event is the native event. #box names an element so the template can read it directly.

Live: {{ name }} · Submitted on Enter: {{ submitted || '—' }}

(keyup.enter) is a key filter built into Angular. In React or jQuery you'd check e.key === 'Enter' yourself.

3. Property, class, style & attribute binding

[x]="expr" sets a DOM property from an expression. Without brackets, the value is just a static string.

width = {{ width }}% · isActive = {{ isActive }}

[class.is-active]="on"toggle one class (≈ classList.toggle, or a clsx condition)
[style.width.%]="w"one style, with a unit suffix (≈ style={{ width: w + '%' }})
[attr.aria-pressed]="on"an HTML attribute, for things that aren't DOM properties (aria-*, data-*, colspan)

4. Using another component

Import the class in imports: [LikeButton], then use its selector as a tag. Each tag is a separate instance with its own state.

Passing data into it (props) is lesson 04. Forgetting the import gives the error "'app-like-button' is not a known element".

Under the hood

There is no virtual DOM. The compiler turns the template into instructions that update only the bound spots. After each click or keystroke, zone.js tells Angular "something may have changed", and Angular re-checks every binding on the page and patches the ones whose value differs.
