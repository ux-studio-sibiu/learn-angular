Lesson 00

Setup & how the app boots

This site runs on Angular {{ angularVersion }}, scaffolded with ng new (≈ create-next-app).

Boot sequence

  1. src/index.html contains an empty <app-root> tag.
  2. src/main.ts calls bootstrapApplication(App, appConfig) (≈ createRoot(el).render(<App/>)).
  3. Angular finds the app-root selector and renders the App component into it.
  4. App's template has <router-outlet />; the router puts the page for the current URL there.

Worth noticing already

  • Standalone components: each component lists what its template uses in imports. No NgModules (the 2017 way).
  • Host elements: inspect the page — you'll see <app-root> and <app-lesson-setup> in the DOM. React leaves no wrapper tags.
  • Scoped styles: the _ngcontent-… attributes are how component CSS is scoped.
  • zone.js is on (provideZoneChangeDetection in app.config.ts). It decides when the screen updates — lesson 10, and it matters a lot for animation.
