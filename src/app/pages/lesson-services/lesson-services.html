Services & dependency injection

A service is a plain class that holds shared state or logic. Dependency injection (DI) is how components get it: they ask with inject(SomeService), and Angular hands them the right instance. No prop drilling, no globals.

2. A service you'll reuse: MotionPreference

One place answers "should we animate?". It follows the OS prefers-reduced-motion setting live, and lets the user override it on this site. The CSS, GSAP and Three.js lessons will all read motion.reduced() instead of each writing its own media query.

@for (m of modes; track m) { } reduced = {{ motion.reduced() }}

It injects PLATFORM_ID, a built-in token, to check it's running in a browser before touching matchMedia. That doesn't matter yet, but on the server (lesson 12) window doesn't exist.

3. Scoped services: one instance per component

Each panel lists providers: [CounterStore], so each gets its own store. The buttons are projected content; they inject "the nearest CounterStore above me" and don't know which panel they're in.

This is how compound components (tabs, accordions, a form and its fields) share state without cloneElement or prop drilling. The parent provides a small store, the children inject it. It's the Angular answer to the accordion pattern in your React components.

Rules worth knowing

  • inject() only works in an injection context: field initializers and the constructor. Not inside a click handler or setTimeout. Similar to the rules of hooks, but about where, not call order.
  • Older code uses constructor injection: constructor(private favorites: FavoritesStore) {}. Same result. inject() is the modern style.
  • DI looks up the tree: the component's own providers, then its parents', then the root. If nothing provides it, you get NullInjectorError: No provider for X.
  • Keep state private and writable inside the service, and expose read-only computeds plus methods (toggle, clear). That's a small store with no library.
  • Before signals, services exposed RxJS BehaviorSubjects and templates used the | async pipe. Expect to see that in existing codebases.
