@defer & performance

@defer wraps part of a template so its components (and everything they import, Three.js included) are downloaded only when a trigger fires. The compiler does the code splitting. It's the tool for heavy 3D heroes and data-viz blocks on long editorial pages.

1. on interaction: poster first, scene on click

The WEF-style hero pattern. A lightweight poster image renders immediately; the "scene" (the bouncing canvas standing in for Three.js) is only fetched when you click. prefetch on idle downloads the chunk while the browser is idle, so the click feels instant.

@defer (on interaction; prefetch on idle) { } @placeholder { } @loading (after 100ms; minimum 400ms) {
Loading scene…
}

@loading (after 100ms; minimum 400ms): don't flash a spinner for fast loads, and if you do show it, keep it long enough not to flicker. Open DevTools → Network before clicking to see the chunk arrive (it may already be there thanks to the prefetch).

@defer (on viewport) { } @placeholder (minimum 300ms) {
Chart placeholder: loads when visible
} @loading (minimum 400ms) {
Loading chart…
}

on viewport needs a placeholder: that's the element Angular watches with an IntersectionObserver. Give it the chart's real height so nothing jumps when it swaps (layout shift, the CLS in Core Web Vitals).

Other triggers: on idle (the default), on immediate, on hover, on timer(2s), and you can combine them: on viewport; on timer(5s). Once loaded, a block never goes back to its placeholder, even if the condition turns false again (use @if for that).

4. NgOptimizedImage: next/image for Angular

Use ngSrc instead of src. It's lazy by default, requires dimensions (no layout shift), and warns in dev mode about common mistakes, like a large image without priority at the top of the page.

  • width + height (or fill) are required: the browser reserves the space before the image loads.
  • priority marks the LCP image: eager, high fetch priority, and a preload hint on the server-rendered page. Everything else is loading="lazy".
  • With an image loader (built-ins for Imgix, Cloudinary, ImageKit, Netlify, or a custom one, e.g. building Sanity image URLs with ?w=), it also generates the srcset, so phones download small files. This demo uses local SVGs, so there's nothing to resize.

Rules & gotchas

  • Deferred components must be standalone and referenced only inside @defer in that file. One stray reference (a viewChild type, a second use outside the block) silently puts it back in the main chunk.
  • Run ng build: each block shows up as its own lazy chunk (named after the component). That's how you check it worked.
  • With SSR (lesson 12), @defer renders the placeholder on the server. Incremental hydration (hydrate on viewport) goes further: render the real content on the server, but only load its JS when needed.
  • Defer is one tool among several: lazy routes (lesson 06), OnPush + signals, running loops outside the zone (lesson 10), bundle budgets in angular.json.
